# Disset Odiseo · Asistente comercial

App web (PWA) que convierte un presupuesto en un catálogo sin precios. Todo el procesamiento ocurre en el navegador: los presupuestos, los precios y los datos de clientes nunca se suben a ningún sitio.

Este repositorio solo contiene la app publicada. No contiene presupuestos, datos de clientes, contraseñas ni claves.
